# Hi, I'm Florian 👋

PhD in high-energy physics from RWTH Aachen University with a focus on machine learning, big-data analysis and scientific software development.
Worked for the CMS experiment at CERN.

My work includes:
- classification and robust neural networks for high-energy physics
- differentiable optimisation methods
- computer vision and generative models
- Python/TensorFlow-based analysis software for large experimental datasets

### Selected projects
- [gato-hep](https://github.com/FloMau/gato-hep) – differentiable optimisation for multidimensional event categorisation
- [HiggsDNA](https://gitlab.cern.ch/cms-analysis/general/HiggsDNA) – major contributor to a collaborative Python analysis framework for CMS H→γγ measurements
- [MiniAOD_photons_to_ML](https://github.com/FloMau/MiniAOD_photons_to_ML) – preparation of CMS photon data for machine-learning applications
