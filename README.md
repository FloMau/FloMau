# Hi, I'm Florian 👋

PhD in high-energy physics from RWTH Aachen University with a focus on machine learning, big-data analysis and scientific software development.
Worked for the CMS experiment at CERN.

My work includes:
- deep neural networks for robust classification in high-energy physics
- differentiable optimisation methods
- computer vision and generative models
- columnar HEP analysis software for large datasets

### Selected projects
- [gato-hep](https://github.com/FloMau/gato-hep) – differentiable optimisation for multidimensional event categorisation ([paper](https://arxiv.org/abs/2601.07756))
- Benchmarking Kolmogorov–Arnold Networks for event classification ([paper](https://arxiv.org/abs/2408.02743))
- Super-resolution of photon showers with generative adversarial networks ([paper](https://arxiv.org/abs/2308.09025))
- Generative parameterised fast simulation with normalizing flows ([paper](https://arxiv.org/abs/2503.21461))
- [HiggsDNA](https://gitlab.cern.ch/cms-analysis/general/HiggsDNA) – major contributor to the Run-3 analysis framework for CMS H→γγ measurements
- [MiniAOD_photons_to_ML](https://github.com/FloMau/MiniAOD_photons_to_ML) – preparation of CMS photon data for machine-learning applications
